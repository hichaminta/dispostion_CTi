Détail de l'Enrichissement : Géolocalisation

Le module geolocalisation/enrichir.py est essentiel pour cartographier l'infrastructure des attaquants. Il permet par exemple au SOC de bloquer instantanément certaines IPs si l'entreprise a une politique interdisant le trafic en provenance de certains pays à risque (Russie, Corée du Nord, etc).

Double Injection Métadonnées (Top-Level & IOC-Level)

NLP Advanced Tags

Ce script est unique car une fois la géolocalisation obtenue, il l'injecte à deux endroits différents du fichier JSON. Il l'injecte dans le champ spécifique de l'indicateur (pour analyser l'IP seule), et il l'injecte dans un tableau global nlp_advanced pour permettre un futur affichage cartographique global sur un Dashboard.

# 1. Niveau de l'IOC
ioc["ioc_enrichment"]["country"] = country_code
ioc["ioc_enrichment"]["country_name"] = country_name

# 2. Niveau "Record" (Global pour le fichier complet)
# Ajoute le pays dans une liste géographique si pas encore présent
geo_list = record["enrichment"]["nlp_advanced"].get("geography", [])
if country_code not in geo_list:
    geo_list.append(country_code)
    record["enrichment"]["nlp_advanced"]["geography"] = sorted(geo_list)

# 3. Injection sous forme de Tag direct pour MISP
tags = record.get("tags", [])
if country_code.lower() not in [t.lower() for t in tags]:
    tags.append(country_code)
    record["tags"] = sorted(list(set(tags)))

Mise en Cache Collective Intelligente (Batch Lookup)

Au lieu de lire les IPs une par une (ce qui pourrait faire appeler l'API 10 fois pour la même IP si elle apparaît 10 fois dans le document), le script exécute une "Phase 1" qui collecte toutes les IPs uniques d'un seul coup (dans un Set), puis appelle l'API pour ce Set restreint, et enfin redistribue les résultats sur tous les IOCs.

# PHASE 1: COLLECT UNIQUE IPs
unique_raw_ips = set()
for record in data:
    for ioc in record.get("iocs", []):
        if ioc.get("type") == "ip":
            unique_raw_ips.add(ioc.get("value"))

# PHASE 2: BATCH LOOKUP AND CACHE POPULATION
lookup_cache = {}
for raw_ip in sorted(list(unique_raw_ips)):
    # Appel à ip-api.com limité en fréquence (45 req/min)
    time.sleep(1.5)
    country_code, country_name = fetch_external_geo(raw_ip)
    lookup_cache[raw_ip] = (country_code, country_name)
