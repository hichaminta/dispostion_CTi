Processus Détaillé de l'Enrichissement (Enrichment)

L'enrichissement est divisé en modules très autonomes qui lisent les fichiers _enriched.json existants, interrogent des API externes, et réécrivent ces mêmes fichiers. Pour économiser les requêtes API (et éviter les blocages), chaque étape utilise une Base de Données Locale (Cache) prioritairement.

Étape 1 : AbuseIPDB (Fichier : enrichir_abuseipdb.py)

IPs Cache Local JSON

Le script charge un fichier abuseipdb_data.json en mémoire au démarrage. Il filtre les IOCs de type "ip". Si l'IP existe dans le cache local, il n'appelle pas l'API ! Sinon, il fait un appel API /api/v2/check, ajoute le résultat au cache local, et l'injecte dans l'IOC.

# Logique de Cache Local
if ip in self.local_db:
    return self.local_db[ip]
else:
    # Appel API
    response = requests.get("https://api.abuseipdb.com/api/v2/check", headers=headers, params={"ipAddress": ip, "maxAgeInDays": 90})
    self.local_db[ip] = response.json().get("data")

# Injection dans l'IOC :
enrichment.update({
    "abuseConfidenceScore": info.get("abuseConfidenceScore"),
    "totalReports":         info.get("totalReports"),
    "countryCode":          info.get("countryCode"),
    "isp":                  info.get("isp"),
    "passer_par_abuseipdb": 1 # FLAG POUR NE PAS REPASSER DESSUS
})

Étape 1b : VirusTotal (Fichier : enrichir_virustotal.py)

Hashes URLs/Domaines IPs

VirusTotal agit comme AbuseIPDB mais de façon bien plus large car il supporte quasiment tous les types d'IOCs. Il a une limite de 4 requêtes par minute (Free tier), c'est pourquoi il intègre un time.sleep(15) strict après chaque appel API.

# Récupération des détections antivirus
stats = attributes.get("last_analysis_stats", {})
return {
    "vt_malicious_count":   stats.get("malicious", 0),
    "vt_suspicious_count":  stats.get("suspicious", 0),
    "vt_harmless_count":    stats.get("harmless", 0),
    "vt_total_engines":     sum(stats.values()) if stats else 0,
    "vt_tags":              attributes.get("tags", []),
}

Fait Intéressant : Si l'URL n'est pas encore connue sur VirusTotal (Statut HTTP 404), le script fait automatiquement une requête POST /urls pour forcer VirusTotal à la scanner pour le lendemain.

Étape 2 : Géolocalisation (Fichier : geolocalisation/enrichir.py)

IP-API Normalisation IPv6

Ce script nettoie spécifiquement les adresses IP (en enlevant les ports comme dans 192.168.1.1:8080 ou les masques CIDR comme /24) et interroge ip-api.com. Il met à jour à la fois le niveau global (record["attributes"]) et le niveau local de l'indicateur (ioc_enrichment).

# Nettoyage rigoureux
def clean_ip_address(ip):
    clean = ip.split('/')[0].strip() # Enleve le subnet
    if clean.startswith('['):        # IPv6 avec port [::1]:80
        clean = clean.split(']')[0][1:]
    elif clean.count(':') == 1 and '.' in clean: # IPv4 avec port
        clean = clean.split(':')[0]
    return clean

Étape 3 : URLScan.io (Sandbox) (Fichier : enrichir_exclusive_urlscan.py)

Asynchrone Whitelisting Profond

Probablement le script le plus impressionnant de l'enrichissement. Contrairement aux autres qui font juste un "GET", l'API d'URLScan est asynchrone (On soumet, on reçoit un UUID, et on doit "Poller" / interroger le serveur jusqu'à avoir la réponse de l'analyse visuelle).

uuid = urlscan.submit_scan(target_value)

# Active Polling (Attente maximale 60 secondes pour que la Sandbox finisse)
attempts = 0
while attempts < 12:
    time.sleep(5)
    result = urlscan.fetch_result(uuid)
    if result and result != "PENDING":
        rich_data = {
            "score": verdicts.get("score", 0),
            "page_title": page.get("title"),
            "screenshot_url": f"https://urlscan.io/screenshots/{uuid}.png",
        }
        break

Le système a aussi une liste blanche `hwite.json` et gère activement les erreurs DNS (si un site de phishing est déjà mort, il le note `DOWN` pour ne jamais ré-essayer).

Étape 5 : CVE & NLP (Fichiers : cve_enrchisment.py et nlp_enrichir.py)

NLP (spaCy) Vulnérabilités

Les vulnérabilités (CVEs) subissent un traitement spécial via la librairie d'Intelligence Artificielle spaCy. Le script nlp_enrichir.py extrait les mots d'une description textuelle pour déduire le type de système touché.

# On lance le modèle NLP en Python via le module d'orchestration
enrich_script = os.path.join(base_dir, "enrichir.py")
nlp_script = os.path.join(base_dir, "nlp_enrichir.py")
subprocess.run([sys.executable, enrich_script])
subprocess.run([sys.executable, nlp_script])
