Détail de l'Enrichissement : Vulnérabilités & Analyse IA

Le module de traitement des CVEs est orchestré par enrichment_cve/cve_enrchisment.py qui lance deux scripts successifs : l'enrichissement NVD standard (score CVSS), suivi de l'analyse en langage naturel (NLP) via Intelligence Artificielle.

Orchestration des Modules (Pipeline dans la Pipeline)

Sous-processus Orchestrateur

Le fichier racine cve_enrchisment.py sert uniquement de chef d'orchestre pour s'assurer que les deux étapes se déroulent dans le bon ordre sans se bloquer mutuellement.

# Extrait de l'Orchestrateur
enrich_script = os.path.join(base_dir, "enrichir.py")
nlp_script = os.path.join(base_dir, "nlp_enrichir.py")

# Lancement Etape 1 (Récupération des Scores depuis la base de données)
subprocess.run([sys.executable, enrich_script] + args, check=False)

# Lancement Etape 2 (Intelligence Artificielle sur la description)
subprocess.run([sys.executable, nlp_script] + args, check=False)

Le Script NLP (Natural Language Processing)

spaCy Extraction d'Entités (NER)

L'étape la plus avancée est nlp_enrichir.py. Quand une vulnérabilité sort, elle a une longue description texte en anglais (ex: "A buffer overflow in Microsoft Windows Server 2019 allows remote attackers to execute arbitrary code..."). L'ordinateur ne comprend pas cette phrase. L'IA NLP entre en jeu.

# 1. Utilisation du modèle linguistique spaCy (anglais)
import spacy
nlp = spacy.load("en_core_web_sm")

# 2. Analyse de la description texte de la vulnérabilité
doc = nlp(description)

# 3. Le dictionnaire de reconnaissance de l'IA (Pattern Matching)
logiciels_reconnus = ["windows", "linux", "apache", "nginx", "cisco", "oracle", "wordpress"]
impacts_reconnus = ["rce", "remote code execution", "privilege escalation", "denial of service"]

for entite in doc.ents:
    # Si spaCy repère une organisation (ex: "Microsoft")
    if entite.label_ == "ORG":
        produits.append(entite.text)
        
    # Si le mot-clé fait partie d'une liste de logiciels dangereux
    if mot in logiciels_reconnus:
        produits.append(mot)

Résultat Final : L'IA transforme le paragraphe en JSON exploitable par la machine : {"produits": ["Windows Server 2019"], "impact": "RCE"}. Ce résultat est inséré dans l'alerte pour avertir le SOC exactement sur quelle machine (Windows, Linux, etc) chercher l'attaque.
