Détail de l'Enrichissement : URLScan.io

Le module enrichment_url/enrichir_exclusive_urlscan.py est la défense principale contre le Phishing. Contrairement à VirusTotal qui regarde des signatures passées, URLScan ouvre un navigateur virtuel (Sandbox) en temps réel, visite le site web, prend une capture d'écran, et analyse la structure de la page pour voir s'il s'agit d'une page de connexion Microsoft ou PayPal piratée.

Validation Heuristique (Whitelisting & Filtres)

Anti-Bruit Whitelist JSON

URLScan est coûteux en quota API. Il ne faut surtout pas lui envoyer n'importe quoi. Avant chaque envoi, le code vérifie :

  1. Si le domaine finit par des extensions techniques ignorables (.exe, .dll, .js, .tmp).
  2. Si le mot est en fait une famille de malware extraite par erreur (ex: trojan.win32).
  3. Si le domaine fait partie d'une Whitelist (hwite.json) pour éviter de scanner Google, Github ou Microsoft.

Processus Asynchrone (Polling Actif)

UUID Polling 60s

Le processus est divisé en deux phases. L'API est asynchrone : on soumet un site, l'API répond immédiatement avec un ticket (UUID), puis il faut "Poller" (interroger régulièrement) l'API jusqu'à ce que la machine virtuelle d'URLScan ait fini l'analyse.

uuid = urlscan.submit_scan(target_value)

# Boucle d'attente (Polling) de 60 secondes maximum
attempts = 0
while attempts < 12:
    time.sleep(5)
    result = urlscan.fetch_result(uuid)
    if result and result != "PENDING":
        # SUCCESS: Le scan est fini, on extrait les résultats.
        break
    attempts += 1

Gestion du Cache et Erreur DNS

Beaucoup de sites de Phishing sont "morts" ou supprimés après quelques jours. Si URLScan renvoie une erreur DNS (le site n'existe plus), le script le met en cache dans la base de registre locale avec le statut DNS_ERROR pour ne plus jamais le vérifier et économiser le quota.

elif uuid == "DNS_ERROR":
