Détail de l'Enrichissement : AbuseIPDB

Le module enrichment_ip/enrichir_abuseipdb.py est spécialisé dans l'analyse de la réputation des adresses IP. Il ajoute un score de malveillance basé sur les signalements de la communauté mondiale de cybersécurité.

Mécanisme de Cache Local Intelligement Conçu

Économie de Quota API JSON Local DB

L'API AbuseIPDB a des limites strictes (ex: 1000 requêtes par jour en compte gratuit). Pour éviter d'épuiser ce quota, le système initialise au démarrage une base locale abuseipdb_data.json en RAM (dans un dictionnaire Python). Lorsqu'une IP doit être analysée :

# Vérification dans le cache local avant appel API
if ip in self.local_db:
    logger.debug(f"[LOCAL] {ip} found in local DB — skipping API call.")
    return self.local_db[ip]
else:
    # Si introuvable, appel de l'API externe
    url = "https://api.abuseipdb.com/api/v2/check"
    headers = {"Key": API_KEY, "Accept": "application/json"}
    params  = {"ipAddress": ip, "maxAgeInDays": 90}
    response = requests.get(url, headers=headers, params=params, timeout=10)
    
    # Enregistrement du résultat dans le cache local pour les prochaines exécutions !
    self.local_db[ip] = response.json().get("data", {})

Nettoyage Dynamique des IPs

Avant d'envoyer l'adresse IP à l'API, le script s'assure qu'elle est "propre". Les extracteurs peuvent remonter des IPs avec un port attaché, ou des plages réseau (CIDR) que l'API AbuseIPDB ne peut pas traiter sur l'endpoint /check.

raw_ip = ioc.get("value")
# Retirer le port s'il est présent (ex: 42.225.207.134:34110 -> 42.225.207.134)
clean_ip = raw_ip.split(":")[0]

# Ignorer les blocs CIDR (ex: 1.10.16.0/20) non supportés par l'endpoint /check
if "/" in clean_ip:
    continue

Données Injectées dans l'IOC

Une fois les informations récupérées, elles sont structurées dans le bloc ioc_enrichment de chaque indicateur. Le script laisse également une "marque" (le flag passer_par_abuseipdb = 1) pour s'assurer que ce fichier ne sera plus jamais traité par ce script s'il est relancé.

enrichment.update({
    "abuseConfidenceScore": info.get("abuseConfidenceScore"), # Le score critique sur 100
    "totalReports":         info.get("totalReports"),         # Le nombre de personnes ayant reporté l'IP
    "lastReportedAt":       info.get("lastReportedAt"),       # Date de la dernière attaque
    "countryCode":          info.get("countryCode"),
    "isp":                  info.get("isp"),                  # Le fournisseur d'accès (ex: OVH, DigitalOcean)
    "source_reliability":   "AbuseIPDB Local/API",
    
    # Le Flag de Tracking
    "passer_par_abuseipdb": 1,
})
