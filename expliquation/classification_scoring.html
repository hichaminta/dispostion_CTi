Détails Complets de Classification et Scoring

Ce document révèle l'ensemble de la logique décisionnelle, de la notation de TOUTES les sources aux mots-clés exacts de classification.

1. Fiabilité des Sources Exhaustive (SourceReliability)

Le fichier reliability.py attribue une note ferme sur 100 à chaque source. Ce score pèsera pour environ 30% à 40% dans le calcul final du risque, évitant ainsi d'inonder le SOC avec des faux positifs venant de sources peu sûres.

3. L'Algorithme de Formule Exacte du Score IOC

Dans scorer.py, la méthode calculate_ioc_risk(ioc, source_confidence) exécute littéralement ce calcul progressif pour pondérer l'importance d'une alerte :

Exemple détaillé pour un HASH :

# 1. On prend le maximum entre la confiance native de la source et la confiance globale du tableau.
base_conf = max(source_confidence, native_confidence)

# 2. Confiance Source (40%)
score += (base_conf / 100.0) * 40.0

# 3. VirusTotal (40%) : Calcul asymptotique basé sur 50 moteurs max
if vt > 0:
    # 20 points garantis dès la première détection, puis calcul glissant jusqu'à +20
    score += 20.0 + min(20.0, ((vt - 1) / 49.0) * 20.0)

# 4. MalwareBazaar Popularité (20%)
if downloads >= 500: score += 20
elif downloads >= 100: score += 15
elif downloads >= 10: score += 10
elif downloads > 0: score += 5

return min(100.0, score) # Capé à 100%

La Guillotine Anti-Faux Positifs :

Si VirusTotal a été appelé et a donné 0 détection malveillante, ET qu'il remonte plus de 20 votes "Inoffensifs" (Harmless), le score est impitoyablement détruit :

if vt_malicious == 0 and vt_harmless > 20:
    score = score * 0.25  # Un score de 80% tombe instantanément à 20% !
