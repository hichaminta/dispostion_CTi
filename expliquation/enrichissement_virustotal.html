Détail de l'Enrichissement : VirusTotal

Le module enrichment_vt/enrichir_virustotal.py est sans doute le plus sollicité de toute la pipeline. Contrairement à AbuseIPDB, VirusTotal est "Multi-Types" : il analyse à la fois les Hashes, les IPs, les Domaines et les URLs.

Routage Multi-Endpoint Intelligent

Multi-Types API v3

L'API v3 de VirusTotal a des URLs différentes selon le type d'objet analysé. Le script implémente un routeur dynamique pour appeler le bon endpoint :

def _call_api(self, ioc_value: str, ioc_type: str):
    if ioc_type == "url":
        result = self._query_url(ioc_value)
    elif ioc_type in ("domain", "domaine"):
        result = self._query_domain(ioc_value)
    elif ioc_type in ("hash", "hashe", "md5", "sha1", "sha256", "sha512"):
        result = self._query_hash(ioc_value)
    elif ioc_type in ("ip", "ipv4"):
        result = self._query_ip(ioc_value)

Encodage Base64 et Forçage de Scan

Pour les URLs, l'API VirusTotal exige que la chaîne soit encodée en Base64 URL-safe (sans signes "égal" à la fin). De plus, si VirusTotal n'a jamais vu cette URL auparavant, il renverra une erreur 404. Le script intercepte ce 404, et fait une requête POST pour forcer VT à analyser l'URL. Le résultat sera disponible la prochaine fois que le script tournera !

# Encodage sécurisé de l'URL
url_id = base64.urlsafe_b64encode(url.encode()).decode().rstrip("=")

r = requests.get(f"{VT_API_BASE}/urls/{url_id}", headers=self._headers())

if r.status_code == 404:
    # 404: L'URL n'est pas dans VirusTotal. On la soumet pour scan.
    requests.post(f"{VT_API_BASE}/urls", headers=self._headers(), data={"url": url})
    return None # On renvoie None. Le flag sera mis à 0 pour réessayer plus tard.

Limitation de Vitesse Sévère (Rate Limiting)

Le palier gratuit de VirusTotal est l'un des plus stricts du marché : 4 requêtes par minute. Le script impose un gel pur et simple de 15 secondes après CHAQUE appel API pour être sûr de ne jamais se faire bannir, rendant le "Cache Local" abordé précédemment absolument vital.

# Si le résultat vient de l'API (et non du cache)
self.local_db[ioc_value] = entry
self._api_calls += 1

# Respect de la limite (free: 4 req/min) -> 15 secondes d'attente
time.sleep(15)

Extraction des Statistiques

Plutôt que d'enregistrer les centaines de lignes renvoyées par VT pour chaque moteur (Avast, Kaspersky, etc), le script extrait uniquement le résumé mathématique pour préparer le terrain au futur calcul de priorité du SOC :

stats = attributes.get("last_analysis_stats", {})
return {
    "vt_malicious_count":   stats.get("malicious", 0),  # Combien disent "Danger"
    "vt_suspicious_count":  stats.get("suspicious", 0), # Combien disent "Bizarre"
    "vt_harmless_count":    stats.get("harmless", 0),   # Combien disent "Sûr" (Faux positifs)
    "vt_total_engines":     sum(stats.values()) if stats else 0, # Sur combien d'AV testés au total
    "vt_reputation":        attributes.get("reputation"),
    "vt_tags":              attributes.get("tags", []),
}
